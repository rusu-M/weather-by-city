Всем привет! Меня зовут Руслан, и это мой учебный проект — я осваивал asyncio и httpx.

Программа отправляет запрос https://www.weatherapi.com/ для получения погоды по конкретному городу. Работает асинхронно: пользователь может передать несколько городов, вводя их через запятую в терминале — запросы по всем городам пойдут сразу.

Что интересного: обработал все частые случаи, и программа будет завершаться, только если у вас проблема с API ключом; есть временные ошибки, в таких случаях корутина попробует еще раз отправить запрос несколько раз (повторы с экспоненциальной задежкой и jitter). Ну и впервые работал с сетью, мне понравилось. Конкурентные запросы ограничены — одновременно 8 штук.

Если захотите воспользоваться, то вам понадобится API KEY, который надо будет положить в файл .env в корень проекта, в переменную "WEATHER_API_KEY". Для этого зарегистрируйтесь на weatherapi (потребуется только почта); установите зависимости из requirements в ваше виртуальное окружение. При запуске в терминале будет предложение для ввода — введите город или города для получения информации о погоде, либо воспользуетесь "test" — там 59 городов. 

Ну в идеале проект еще изменится: я применю другие инструменты из asyncio или threads.
